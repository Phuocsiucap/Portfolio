# Nguyen Van Phuoc — Backend Developer Portfolio

A responsive, minimal personal portfolio built with React, TypeScript, Vite, and Lucide icons.

## Requirements
- Node.js 18+

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
npm run preview
```

## Customize before publishing
1. Confirm the email address in `src/App.tsx`.
2. Add your real LinkedIn profile URL (currently a generic LinkedIn homepage link).
3. If you want a downloadable CV button, place your updated PDF in `public/` and add a link in the hero section.
4. Verify all project descriptions and repository URLs before sharing publicly.

## Deploy
- Push this folder to a GitHub repository.
- Import the repository into Vercel.
- Framework preset: Vite.
- Build command: `npm run build`.
- Output directory: `dist`.

The content is based on the CV supplied in this conversation. Private employer platform names are not expanded beyond what was included in the CV.
